# Карта клавиш Digitable Session

Три слоя не пересекаются, и это главное правило раскладки:

| Слой | Модификатор | Кто обрабатывает |
|---|---|---|
| Рабочий стол | **Mod4** (Super/Windows) | оконный менеджер |
| Редактор | Ctrl, Alt, Shift, F7–F12, `\` | vim |
| Мультиплексор | Ctrl+b | tmux |

Оконный менеджер намеренно не берёт ни Ctrl+hjkl, ни Alt+hjkl, ни F-клавиши:
в конфигурации vim из dotfiles они заняты переходом между окнами, изменением
их размера и floaterm. Если бы менеджер их перехватывал, редактор перестал бы
их видеть.

## Рабочий стол (Mod4)

### Фокус и окна

| Клавиши | Действие |
|---|---|
| `Mod4+h` / `Mod4+l` | предыдущее / следующее окно (в будущей ленте — колонка левее/правее) |
| `Mod4+k` / `Mod4+j` | предыдущее / следующее окно внутри группы |
| `Mod4+Tab` / `Mod4+Shift+Tab` | перебор окон вперёд / назад |
| `Mod4+Shift+h j k l` | двигать окно |
| `Mod4+Ctrl+h j k l` | менять размер окна |
| `Mod4+←↑↓→` | прижать окно к краю экрана |
| `Mod4+c` | окно по центру |
| `Mod4+v` | окно занимает левую колонку (`vtile`, 40 %) |
| `Mod4+s` | окно занимает верхнюю полосу (`htile`, 50 %) |
| `Mod4+f` | во весь экран, без рамки и отступов |
| `Mod4+m` | развернуть с учётом рамки и отступов |
| `Mod4+q` | закрыть окно |
| `Mod4+w` | спрятать окно |
| `Mod4+r` / `Mod4+d` | поднять / опустить окно |
| `Mod4+t` | заморозить геометрию окна |
| `Mod4+y` | закрепить окно на всех рабочих столах |
| `Mod4+n` | подписать окно |

### Рабочие столы (группы cwm)

| Клавиши | Действие |
|---|---|
| `Mod4+1` … `Mod4+9` | показать только эту группу |
| `Mod4+Shift+1` … `9` | перенести окно в группу |
| `Mod4+0` | показать все группы |
| `Mod4+a` | вернуться к предыдущей группе |
| `Mod4+[` / `Mod4+]` | перебор групп |
| `Mod4+g` | добавить или убрать окно из группы |

### Меню

| Клавиши | Действие |
|---|---|
| `Mod4+space` | запустить программу |
| `Mod4+p` | меню приложений |
| `Mod4+/` | поиск по открытым окнам |
| `Mod4+,` | меню групп |
| `Mod4+.` | меню ssh |
| ЛКМ / СКМ / ПКМ по фону | окна / группы / приложения |
| `Alt+ЛКМ`, `Alt+ПКМ` | двигать, растягивать окно |

### Запуск и сессия

| Клавиши | Действие |
|---|---|
| `Mod4+Return` | терминал |
| `Mod4+Shift+Return` | терминал с рабочей сессией tmux |
| `Mod4+e` | vim |
| `Mod4+b` | btop |
| `Mod4+o` | lf |
| **`Mod4+`` `** | **Digit** — открыть или поднять окно агента |
| `Mod4+x` | заблокировать экран |
| `Mod4+Ctrl+Shift+r` | перезапустить оконный менеджер |
| `Mod4+Ctrl+Shift+q` | выйти из сессии |

## Редактор (vim и neovim)

Лидер — `\`, как в dotfiles. Полный список показывает which-key: нажмите `\`
и подождите. Он же показывается при запуске (отключается
`let g:digitable_show_keys_on_start = 0`).

| Клавиши | Действие |
|---|---|
| `\w` `\x` `\q` | сохранить, сохранить и выйти, выйти из всех окон |
| `\v` `\h` | вертикальное и горизонтальное разделение |
| `\ot` | терминал внизу |
| `\e` `\E` | проводник NERDTree: открыть, найти текущий файл |
| `\lf` `\l` | файловый менеджер lf |
| `\g` `\P` `\sf` | поиск по содержимому (ripgrep + fzf + bat) |
| `\o` | быстрый поиск файлов (fd + fzf) |
| `\p` | палитра команд |
| `\b` | список буферов |
| `\f` | форматировать |
| `\ca` `\c` `\cf` | скопировать файл, скопировать выделение, очистить файл |
| `\m`, ПКМ | контекстное меню: переходы, документация, переименование |
| `\gg` `\gc` `\gp` `\gl` | git: панель, коммит, push, pull |
| `\1` … `\9`, `\0` | вкладки по номеру, последняя вкладка |
| `\sr` `\sc` | замена по файлу, замена с подтверждением |
| `\R` | перечитать конфигурацию сессии |
| `Ctrl+h j k l` | переход между окнами |
| `Alt+h j k l` | размер окон |
| `Shift+h j k l` | курсор на 10 позиций |
| `gb` `gbp` `gbd` | следующий, предыдущий, закрыть буфер |
| `gd` `gy` `gi` `gr` | определение, тип, реализация, ссылки |
| `K` | документация |
| `Space` | свернуть / развернуть |
| `F7` `F8` `F9` `F12` | терминалы floaterm: новый, предыдущий, следующий, показать |
| `Ctrl+p` `Ctrl+f` `Ctrl+b` | файлы, поиск, буферы |
| `Ctrl+s` `Ctrl+z` `Ctrl+a` | сохранить, отменить, выделить всё |
| `Ctrl+d` | мультикурсор на следующее вхождение |

## Мультиплексор (Ctrl+b)

| Клавиши | Действие |
|---|---|
| `Ctrl+b` `\|` / `-` | разделить панель по вертикали / горизонтали |
| `Ctrl+b` `h j k l` | переход между панелями |
| `Ctrl+b` `H J K L` | размер панели (повторяемо) |
| `Ctrl+b` `c` | новое окно в текущем каталоге |
| `Ctrl+b` `r` | перечитать конфигурацию |
| `Ctrl+b` `D` | рабочая сессия из dotfiles |
| `Ctrl+b` `Escape` | режим копирования, дальше `v` и `y` как в vim |

## Оболочка

| Команда | Действие |
|---|---|
| `dev` | рабочая сессия tmux: development, infos, net, downloads, containers, digit |
| `d` | Digit |
| `digitwm-keys` | этот файл |
| `rgf` | поиск по содержимому в терминале |
| `projects`, `downloads` | переход в каталоги |

Алиасы `ls`, `cat`, `du`, `df`, `find`, `grep`, `ps`, `ping`, `cd` заменены на
eza, bat, dust, duf, fd, rg, procs, gping и zoxide — но каждый только если
замена действительно установлена.

## Что изменено против dotfiles и почему

В конфигурации vim четырнадцать помеченных отличий (ищите слово `ОТЛИЧИЕ` в
`~/.config/digitwm/vimrc`). Существенные:

1. `Ctrl+h` остаётся переходом в левое окно. В dotfiles он ниже по файлу
   переопределён на `:%s///g`, и переход переставал работать вопреки
   собственной документации. Замена переехала на `\sr`.
2. `Ctrl+r` остаётся штатным redo. В dotfiles он занят заменой с
   подтверждением — она теперь на `\sc`.
3. `set paste` убран: он глобально выключает маппинги вставки, автоотступ и
   сниппеты, то есть половину настроенного.
4. `set hidden` вместо противоречивой пары `hidden` + `nohidden`, иначе
   переключение буферов теряет несохранённые правки.
5. Тяжёлые плагины (coc.nvim, YouCompleteMe, vim-go, prettier,
   markdown-preview) не ставятся по умолчанию: включаются
   `let g:digitable_heavy = 1`.
6. `colorscheme dracula_pro` заменён на Digitable Focus. Dracula Pro —
   платная тема, её нельзя ни класть в репозиторий, ни ставить за
   пользователя.
